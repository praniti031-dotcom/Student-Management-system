
# 📚 Student Task Management System
A **Student Task Management System** is a responsive web application developed to help students organize their academic activities, manage daily tasks, and improve study productivity. The application enables users to track study sessions, manage assignments through an interactive calendar, monitor learning progress, and receive reminders for upcoming tasks.
This project was developed to provide students with a simple and efficient platform for planning their study routine and maintaining consistency in their academic goals.
---
## 📌 Problem Statement
Students often struggle to manage multiple assignments, examinations, and study schedules, leading to missed deadlines and reduced productivity.

The **Student Task Management System** aims to solve this problem by providing an organized platform where students can plan their tasks, monitor study hours, and stay updated with upcoming academic activities.
---
## ✨ Features
- 📖 Study Session Tracker
  - Record the subject studied
  - Select study type (Reading or Practice)
  - Log focused study hours

- 📊 Performance Analysis
  - Analyze study sessions
  - Monitor productivity
  - Track study progress

- 📅 Interactive Calendar
  - Add daily academic tasks
  - View scheduled activities
  - Organize assignments and deadlines

- ✅ Task Management
  - Mark tasks as completed
  - Track pending and completed tasks
  - Improve daily productivity

- ⏰ Task Reminders
  - Receive reminders for upcoming tasks
  - Stay consistent with study schedules

- 💻 Responsive & User-Friendly Interface
  - Clean and intuitive design
  - Works across desktop and mobile devices
